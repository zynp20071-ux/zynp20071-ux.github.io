HakkımdaAbout me

Merhaba,Hello, ben Zeynep.I’m Zeynep.

Bilgisayar programcılığı öğrencisiyim. Kod yazmayı, özellikle de yazdığım şeyin ekranda canlandığını görmeyi seviyorum. I’m a computer programming student. I love writing code, especially seeing what I build come alive on screen.

Akdeniz Üniversitesi’nde Bilgisayar Programcılığı okuyorum. Zamanımın çoğu yazılımla geçiyor: HTML, CSS ve JavaScript ile web sayfaları hazırlıyor, Python ve C# ile küçük programlar ve denemeler yazıyorum. Bir şeyi kodlayıp çalıştığını görmek bana hâlâ oyun oynamak kadar keyif veriyor.

Oyunlara ve etkileşimli web deneyimlerine olan ilgim de buradan geliyor; bu siteyi de ziyaretçinin oynayarak gezebileceği şekilde tasarladım. Kodun dışında en sevdiğim şey arkadaşlarımla vakit geçirmek. Hedefim, insanların kullanırken keyif aldığı yazılımlar geliştirmek.

I study Computer Programming at Akdeniz University. Most of my time goes into software: I build web pages with HTML, CSS and JavaScript, and write small programs and experiments in Python and C#. Coding something and watching it work is still as much fun for me as playing a game.

That is also where my interest in games and interactive web experiences comes from; I designed this site so visitors can explore it by playing. Outside of code, my favourite thing is spending time with my friends. My goal is to build software people enjoy using.
